# CrystalChess multiplayer server

Authoritative WebSocket game server. The server owns every position, every
legality decision and both clocks — clients only ever *propose* moves.

Node 22, ESM, **no build step**. Dependencies: `ws` and the project's own rule
engine bundle (`server/vendor/variant-engine.mjs`, generated by
`scripts/build-server-engine.mjs`). The wire format is defined by
`src/multiplayer/protocol.ts`, which is authoritative.

## Run locally

```bash
node server/index.mjs             # ws://0.0.0.0:8787
curl localhost:8787/health        # {"ok":true,"rooms":0,"clients":0}
```

The default client URL (`DEFAULT_SERVER_URL` in `protocol.ts`) is
`ws://127.0.0.1:8787`, so no configuration is needed for local development.

## Test

```bash
node server/test-server.mjs       # 166 assertions, prints PASS/FAIL, exits 1 on failure
```

The harness boots real servers on ephemeral ports, connects real `ws` clients
and plays complete games (standard, Chess960, Fog of War).

## Environment

| Variable | Default | Purpose |
| --- | --- | --- |
| `PORT` | `8787` | WebSocket **and** `/health` port. |
| `HOST` | `0.0.0.0` | Bind address. |
| `ABANDON_GRACE_MS` | `30000` | Reconnection window before a dropped player forfeits. |
| `QUIET` | *(unset)* | Set to `1` to silence per-event logging. |
| `TEST_FAST_CLOCK_MS` | *(unset)* | **Test only.** Overrides the initial time of every time control (except `unlimited`) with this many milliseconds, so flag-fall can be exercised in under a second instead of a minute. |
| `TEST_CHESS960_ID` | *(unset)* | **Test only.** Pins every Chess960 game to this position id (`0`–`959`) instead of drawing one at random, making castling tests deterministic. |

The two `TEST_*` hooks exist purely so the test suite stays fast and
deterministic; leave them unset in production. `startServer()` is also exported
from `server/index.mjs` and accepts the same settings as options
(`port`, `host`, `initialMsOverride`, `chess960Id`, `abandonGraceMs`, `quiet`),
which is how `test-server.mjs` boots in-process servers.

## HTTP endpoint

`GET /health` → `200 {"ok":true,"rooms":N,"clients":N}` on the same port as the
WebSocket endpoint. Every other path returns `404`.

## Deploy

Any platform that can run a long-lived Node process and proxy WebSockets.

```bash
# anywhere with Node 22
npm ci --omit=dev
PORT=8787 HOST=0.0.0.0 node server/index.mjs
```

```ini
# systemd: /etc/systemd/system/crystalchess.service
[Service]
WorkingDirectory=/srv/crystalchess
Environment=PORT=8787 QUIET=1
ExecStart=/usr/bin/node server/index.mjs
Restart=always
```

Notes for a hosted deployment:

- Terminate TLS at a reverse proxy and forward upgrade headers
  (`Connection: upgrade`, `Upgrade: $http_upgrade`), then point clients at
  `wss://…`.
- Set the proxy read timeout above 60s, or rely on the server's own 5s
  WebSocket ping frames to keep idle connections alive.
- Use `/health` as the liveness/readiness probe.
- State is in-memory: a restart drops live games, and the process does **not**
  scale horizontally without a shared room registry. Run a single instance, or
  shard by room code.

## Design notes

**Clocks.** The server stores canonical remaining milliseconds per colour. On
each move it charges `now - turnStartedAt` minus a lag credit of
`min(rtt/2, 150)` ms (floored at 0), adds the Fischer increment and starts the
opponent. The *first* move of the game is free. RTT is a median over recent
samples drawn from both WebSocket pong frames (true server-measured round
trips) and application `ping {t0}` messages (one-way delay against a running
clock-offset baseline). Flag-fall is adjudicated by a server timer, armed
`150ms` beyond the remaining time so a move already in flight still counts; the
win is downgraded to `timeout-vs-insufficient` when the winner holds only a bare
king, king + one knight or king + one bishop. `unlimited` reports
`clocks: null`.

**Reconnection.** A dropped player keeps their seat for `ABANDON_GRACE_MS`;
re-sending `join {code}` reclaims it. If the window closes during a live game
the result is `abandoned` in favour of whoever is still present.

**Colours** are drawn from `crypto.randomInt`, never from queue or join order,
and are swapped on every rematch.
